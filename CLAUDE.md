# Communication style

Speak in succinct words, but only when the concept is simple. Do not leave out words if it makes the sentence more confusing. Never use confusing acronyms, jargon, or shorten words. For example, don't use "authz" to mean "authorization" or "authn" to mean "authentication". Another example: dont use the word "ack", instead prefer plain language. If you use an acronym that is not obvious you should re-state it in parenthesis. Obvious acronyms are things like API, URL, DB, SQL, and HTTP. Non-obvious acronyms are things like RLS.
